# Painel CX PWA

PWA simples para apoiar a mediação do painel **Conexão com Tecnologia: IA, Automação e o Papel do Humano**.

## Recursos

- cronômetro fixo
- navegação por toque nas laterais e swipe
- modo tela cheia
- ajuste de tamanho de texto
- orientação paisagem
- persistência do slide atual e tamanho de fonte
- funcionamento offline após a primeira abertura

## GitHub Pages

Ative em `Settings > Pages > Deploy from a branch`, escolhendo `main` e `/ (root)`.

A URL esperada será:

`https://roavelino.github.io/cx-panel/`

No iPhone, abra essa URL no Safari e use `Compartilhar > Adicionar à Tela de Início`.
